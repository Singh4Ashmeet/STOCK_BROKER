# Infrastructure

Docker Compose profiles and configuration for local development and demo deployment.

## Profiles

| Profile | Services | Description |
|---------|----------|-------------|
| `core` | postgres, redis | Required for API |
| `analytics` | clickhouse | Optional for backtesting/candles |
| `obs` | prometheus, grafana | Observability stack |
| `bus` | redpanda | Message bus (optional) |
| `app` | feed, api, research, web | Application services |

## Quick Start

```bash
# Start core infrastructure (PostgreSQL, Redis)
docker compose --profile core up -d

# Start observability
docker compose --profile core --profile obs up -d

# Start full application stack
docker compose --profile core --profile app up -d --build

# Start everything
docker compose --profile core --profile analytics --profile obs --profile app up -d --build
```

## Environment Variables

Create `.env` from `.env.example` (generated by `scripts/bootstrap.sh`):

```bash
cp .env.example .env
# Edit .env with your values
```

Required variables:
- `SB_POSTGRES_MIGRATOR_PASSWORD` - PostgreSQL migrator role password
- `SB_POSTGRES_APP_PASSWORD` - PostgreSQL app role password
- `SB_POSTGRES_READONLY_PASSWORD` - PostgreSQL readonly role password
- `SB_REDIS_PASSWORD` - Redis password
- `SB_CLICKHOUSE_PASSWORD` - ClickHouse password
- `SB_CLICKHOUSE_APP_PASSWORD_SHA256` - ClickHouse app user password (SHA256)
- `SB_GRAFANA_ADMIN_USER` - Grafana admin username
- `SB_GRAFANA_ADMIN_PASSWORD` - Grafana admin password
- `SB_POSTGRES_PORT` - PostgreSQL port (default 5432)
- `SB_REDIS_PORT` - Redis port (default 6379)
- `SB_CLICKHOUSE_HTTP_PORT` - ClickHouse HTTP port (default 8123)
- `SB_CLICKHOUSE_NATIVE_PORT` - ClickHouse native port (default 9000)
- `SB_PROMETHEUS_PORT` - Prometheus port (default 9090)
- `SB_GRAFANA_PORT` - Grafana port (default 3000)
- `SB_REDPANDA_PORT` - Redpanda port (default 9092)

## Services

### PostgreSQL (core)
- Image: `postgres:16.4-alpine`
- Database: `stockbroker`
- Roles: `sb_migrator` (DDL), `sb_app` (DML), `sb_readonly` (SELECT)
- Init scripts: `infra/postgres/init/`
- Port: `${SB_POSTGRES_PORT}:5432` (bound to 127.0.0.1)

### Redis (core)
- Image: `redis:7.4-alpine`
- Password from `SB_REDIS_PASSWORD`
- Max memory: 256MB, LRU eviction
- Port: `${SB_REDIS_PORT}:6379` (bound to 127.0.0.1)

### ClickHouse (analytics)
- Image: `clickhouse/clickhouse-server:24.8-alpine`
- Database: `stockbroker`
- Users: `default` (admin), `sb_app` (via users.d template)
- Port: `${SB_CLICKHOUSE_HTTP_PORT}:8123`, `${SB_CLICKHOUSE_NATIVE_PORT}:9000`

### Prometheus (obs)
- Image: `prom/prometheus:v2.54.1`
- Config: `infra/prometheus/prometheus.yml`
- Port: `${SB_PROMETHEUS_PORT}:9090`

### Grafana (obs)
- Image: `grafana/grafana:11.1.4`
- Provisioning: `infra/grafana/provisioning/`
- Dashboards: `infra/grafana/dashboards/`
- Port: `${SB_GRAFANA_PORT}:3000`

### Redpanda (bus, optional)
- Image: `docker.redpanda.com/redpandadata/redpanda:v24.2.10`
- Single node dev mode
- Port: `${SB_REDPANDA_PORT}:9092`

### Application Services (app)
See individual service docker-compose files:
- `infra/feed/docker-compose.yml` - Rust feed service
- `infra/api/docker-compose.yml` - Java API
- `infra/research/docker-compose.yml` - Python research
- `infra/web/docker-compose.yml` - Next.js frontend

## Networks

All services share the `sb_internal` bridge network.

Named volumes for persistence:
- `postgres_data`
- `redis_data`
- `clickhouse_data`
- `prometheus_data`
- `grafana_data`
- `redpanda_data`

## Health Checks

All services have health checks configured. Use `docker compose ps` to verify.

## Secrets

JWT keys and other secrets are mounted as Docker secrets (not in compose file).
Generate with `scripts/bootstrap.sh`.

## Resource Limits

Each service has CPU/memory limits and reservations defined for demo deployment.

## Development Tips

```bash
# View logs
docker compose logs -f postgres

# Execute commands in container
docker compose exec postgres psql -U sb_migrator -d stockbroker

# Reset database
docker compose down -v
docker compose --profile core up -d

# Check resource usage
docker stats
```
